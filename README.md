## Student Management & CGPA Dashboard
A Python-based student Management System built using Streamlit and SQLite.

## Features
- Add students
- View students
- Delete Students
- Add subject marks.
- Calculate grades.
- Calculate SGPA
- vStudent performance dashboard
- SGPA visualization
- SQLite database
## Technologies Used
- python
- Streamlit
- SQLite
- Pandas
- Git
- GitHub
